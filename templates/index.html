Academic Field Project Report & Mathematical Foundations

                
This empirical project integrates 11 core data mining concepts implemented from scratch in pure Python to analyze university students' financial habits.


                

                    
Key Formulations Implemented:

                    

                        1. Shannon's Entropy:
                        

                            $$H(S) = - \sum_{i=1}^{k} p_i \log_2(p_i)$$
                        

                    

                    

                        2. C4.5 / J48 Gain Ratio:
                        

                            $$GainRatio(S, A) = \frac{IG(S, A)}{SplitInfo(S, A)}$$
                        

                    

                    

                        3. Apriori Association Rule Lift:
                        

                            $$Lift(A \implies B) = \frac{Confidence(A \implies B)}{Support(B)} = \frac{P(A \cap B)}{P(A) \cdot P(B)}$$
                        

                    

                    

                        4. Bayes' Posterior Probability:
                        

                            $$P(C|X) = \frac{P(C) \prod_{i=1}^{n} P(x_i|C)}{P(X)}$$
